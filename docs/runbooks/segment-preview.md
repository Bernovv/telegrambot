# Предварительный просмотр сегмента

## Доступ

- Страница: `/segments`.
- API: `POST /api/v1/segments/preview`.
- Право: `users.read`.
- Для выбора значений необходимы активные статусы или категории в `/classification`.

## Правила выражения

- Оператор над группами: `И` либо `ИЛИ`.
- В каждой группе действует собственный оператор `И` либо `ИЛИ`.
- `Любой из` требует хотя бы одно активное назначение из выбранных.
- `Все выбранные` требует каждое выбранное активное назначение.
- `Исключить` оставляет пользователей без любого из выбранных назначений.
- Не более восьми групп, восьми условий в группе, двадцати кодов в условии и пятидесяти
  пользователей в выборке.

## Нормальное поведение

Результат показывает точное количество совпавших пользователей и до двадцати последних
зарегистрированных пользователей в интерфейсе. Расчёт выполняется только для чтения и ничего не
назначает, не снимает и не отправляет.

## Диагностика

- HTTP 400 `INVALID_ADMIN_SEGMENT_PREVIEW`: проверьте размеры, операторы и непустые условия.
- HTTP 422 `ADMIN_SEGMENT_CLASSIFICATION_UNAVAILABLE`: перечитайте каталог; один из кодов
  отсутствует или выключен.
- HTTP 403: роли не хватает `users.read` либо сессия администратора недействительна.
- Медленный расчёт: уменьшите выражение и проверьте индексы активных назначений. Не заменяйте
  preview ручным SQL.

## Ограничения

Preview динамический. Он не фиксирует конкретных получателей и не запускает отправку.

## Сохранённые версии

- `GET /api/v1/segments` — список, право `users.read`.
- `GET /api/v1/segments/:id` — текущий черновик и опубликованная версия, право `users.read`.
- `POST /api/v1/segments` — новый черновик, право `broadcasts.send`.
- `PATCH /api/v1/segments/:id/draft` — сохранить текущий или создать следующий черновик,
  право `broadcasts.send`.
- `POST /api/v1/segments/:id/publish` — опубликовать черновик, право `broadcasts.send`.

Для каждого изменения обязательны причина и актуальный `expectedLockVersion`. HTTP 409
`ADMIN_SAVED_SEGMENT_VERSION_CONFLICT` означает, что сегмент уже изменил другой администратор:
перезагрузите его перед повторным сохранением. Опубликованная версия неизменяема.

Готовый снимок аудитории можно связать с опубликованной версией рассылки и использовать при
планировании. Массовые операции вне рассылок ещё не реализованы.
