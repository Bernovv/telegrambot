# ADR 0040. Staging CSV-импорта пользователей

## Статус

Принято.

## Контекст

Импорт пользовательских данных требует нормализации, поиска совпадений, решения конфликтов и
транзакционного объединения. Немедленное изменение пользователей при загрузке файла не оставляет
оператору безопасного предпросмотра и повышает риск ошибочного массового обновления.

## Решение

- Первый срез принимает только CSV в UTF-8 размером до 512 КиБ и до 5000 строк.
- Поддерживаются разделители запятая, точка с запятой и табуляция. Парсинг выполняет
  `csv-parse` 7.0.1 со строгим числом столбцов.
- Разрешены заголовки `telegram_id`, `telegram_username`, `phone`, `external_crm_id`,
  `first_name`, `last_name`. В файле должен присутствовать хотя бы один столбец идентичности.
- Телефон нормализуется существующим адаптером libphonenumber в E.164. Telegram username
  нормализуется без `@` и в нижнем регистре.
- Формулы в текстовых полях, некорректные идентификаторы и строки без идентичности не попадают в
  нормализованный payload.
- Одинаковые нормализованные строки внутри файла получают `IGNORED`; ошибки получают `INVALID`;
  остальные строки получают предварительный статус `NEW`.
- SHA-256 исходных байтов является ключом дедупликации batch. Одновременная повторная загрузка
  возвращает уже созданный batch.
- Исходный файл и необработанные строки не сохраняются. Append-only staging хранит только
  нормализованный payload, безопасные коды ошибок и hash строки.
- Создание batch и строк выполняется одной транзакцией вместе с audit без персональных данных.
- Срез не ищет пользователей в основной модели и не выполняет merge.

## Последствия

- Оператор может проверить структуру и качество файла до изменения пользовательских данных.
- Файл с тем же checksum не создаёт дубликаты staging.
- Поиск точных и возможных совпадений, решения конфликтов, chunked merge и отчёт выполнения
  требуют следующих версий.
- Staging содержит персональные данные и требует ограниченного доступа, retention и удаления
  отдельной подтверждённой операцией; автоматическое удаление в этом срезе не выполняется.

## Совместимость

Миграция `20260731100000_user_import_staging` только добавляет таблицы и append-only триггеры.
Действующие таблицы пользователей, контактов и Telegram identities не меняются.
